# Code Overlay

Make a "Use Code" creator code overlay and download it as a transparent PNG. Everything runs in your browser.

Open `index.html` or turn on GitHub Pages for this repo (Settings > Pages > Deploy from branch > `main` / root).

- Click the text in the preview to edit it in place
- Gradient or solid code box, black or white code text, box rounding
- Label and #AD colours, background colour, opacity (50% by default) and rounding
- Four presets plus your own saved ones
- Download PNG at 1x to 8x, or copy it to the clipboard

Uses Burbank Big Condensed Bold (House Industries), embedded in the page with permission.
