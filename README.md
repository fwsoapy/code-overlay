# Code Overlay

Make a "Use Code" creator code overlay (the Fortnite-style one) and download it as a transparent PNG. Everything runs in your browser.

Open `index.html` or turn on GitHub Pages for this repo (Settings > Pages > Deploy from branch > `main` / root).

- Colours for the label, #AD text, code text (black / white / custom) and backing
- Gradient or solid code box, with angle and opacity
- Background opacity (50% by default)
- Fonts, sizes, slant, padding, corners, swap sides, text shadow
- Presets, including the default everyone uses, plus your own saved ones
- Download PNG at 1x to 8x, or copy straight to the clipboard
